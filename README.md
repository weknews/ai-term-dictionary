# 위뉴 AI 용어집

AI 씬 용어 283개를 정의 · 업계 뉘앙스 · 관찰 시점 현황 세 층으로 정리한 내부 공유 문서.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 문서 본체 (마크업 · 스타일 · 검색/탭 로직) |
| `terms.js` | **용어 데이터 — 갱신할 때 여기만 고친다** |
| `check.py` | **발행 전 점검** — 무결성·수치·표현·윤문·반복·리듬 |
| `build.py` | 공유용 단일 HTML 빌드 (점검을 먼저 돌린다) |
| `CONTRIBUTING.md` | 갱신 규칙, 시점 표기 규칙, 동향 수집 명령 |
| `dist/위뉴-AI-용어집.html` | 빌드 결과물 (git 추적 안 함) |

## 공유용 파일 만들기

```bash
python3 build.py
# check.py를 먼저 돌리고, 통과해야 빌드된다
# → dist/위뉴-AI-용어집.html
```

점검만 따로 돌리려면 `python3 check.py`.

`terms.js`를 본문에 인라인한 **단일 파일**이다. 메일에 붙이든, 사내 위키에 올리든, 드라이브에 두든
그 파일 하나만 있으면 그대로 열린다. 글꼴만 Google Fonts에서 받아오므로 오프라인에서는
시스템 글꼴로 대체돼 표시된다 (레이아웃은 유지된다).

## 로컬에서 보기

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`file://`로 직접 열면 브라우저 보안 정책 때문에 `terms.js`가 로드되지 않을 수 있다.
그 경우 `dist/` 빌드 결과물을 열면 된다 (단일 파일이라 제약이 없다).

## 구성

- **시작** — 왜 만들었나, 관찰 시점, 에이전트 6단 사다리, 읽는 법
- **상황별** — 실제로 말이 오가는 일곱 자리에 맞춰 묶은 42개. 사전이 단어로 찾는다면 이쪽은 자리로 찾는다
- **용어 사전** — 270개 / 13개 분류. 전문 검색, 분류·플래그 필터
- **유행의 역사** — ChatGPT 이후 시기별 열기와 결과. 당시 주장과 지금을 나란히
- **어디까지 왔나** — 2026-09-22 기준 현장 스냅샷 (유통기한 가장 짧음)
- **더 정확하게** — 바꿔 말하기 치트시트
- **갱신** — 변경 이력

주소에 `#terms`, `#now` 같은 해시가 붙으므로 특정 구역을 바로 링크할 수 있다.
`/` 키를 누르면 검색으로 바로 간다.
